# 首页重设计:超大标题 + 不对称编辑版式

## 设计方向
基于你现有的暖白主题(Bricolage Grotesque + Outfit + 暖橘 clay 强调),重写首页两个核心区块,建立强信息层次和编辑感。

---

## 第 1 部分:首屏 Hero 重写

### 版式:7/5 不对称,标题左对齐占主导

```
┌─────────────────────────────┬──────────────┐
│                             │ 工程验证      │
│ AI AGENT / RAG              │ ─────────    │
│                             │ 286+ 测试     │
│ 可追问的                     │ 114+ Eval    │
│ AI 简历分身                  │ 2 独立项目   │
│ ← text-7xl/8xl 超大标题      │              │
│                             │ keywords...  │
│ 简短说明文案一两行...         │              │
│                             │              │
│ [与AI分身交流] [查看项目]     │              │
└─────────────────────────────┴──────────────┘
```

### 关键改动
- **标题放大**:`text-6xl` -> `text-7xl lg:text-8xl`,字重 bold,行高压紧 `leading-[0.95]`,左对齐
- **标题分两行**:第一行小字标签(`AI AGENT / RAG 应用开发`,mono 字体,clay 色,`text-sm`),第二行超大主标题
- **强层次对比**:标签 `text-sm` vs 标题 `text-8xl` vs 说明 `text-base` vs 辅助数据 `text-xs` -- 四级明显落差
- **右侧辅助面板**:精简为纯数据(数字大 + 标签小),去掉花哨的渐变顶条,改用极简分隔线
- **关键词移到底部**:斜杠分隔,横跨整行,作为首屏收尾
- **留白**:整体 `py-16 lg:py-24`,给标题呼吸空间

### 网格
`lg:grid-cols-[1.4fr_0.6fr]` -- 标题区占 70%,辅助区占 30%

---

## 第 2 部分:项目区重写 -- 不对称双栏

### 版式:一大一小,主次分明

```
┌─────────────────────────┬────────────┐
│ 01 ── 主项目             │ 02         │
│                         │ 次项目      │
│ NovaMind                │            │
│ ← text-5xl 大标题        │ Notebook   │
│                         │ ← text-3xl  │
│ 透明可控的 Agent 框架     │            │
│ ← 小字说明               │ Agentic RAG│
│                         │ 小字说明    │
│ [作品图片占位区]          │            │
│ ← 16:9 灰底占位,你后放图  │ [图片占位]  │
│                         │            │
│ tags / GitHub ->        │ tags/GitHub│
└─────────────────────────┴────────────┘
```

### 关键改动
- **不对称网格**:`lg:grid-cols-[1.5fr_1fr]` -- 左侧主项目占 60%,右侧次项目占 40%
- **主项目(左,大)**:
  - 序号 `01` mono 字体 + 分隔线
  - 标题 `text-5xl font-display` 大字
  - 说明 `text-sm` 小字,形成对比
  - **作品图片占位区**:`aspect-[16/9]` 灰底虚线框,中间放"作品图片占位"文字 + 图标,你后面替换成真实图片
  - tags + GitHub 链接
- **次项目(右,小)**:
  - 序号 `02`
  - 标题 `text-3xl` 比主项目小
  - 说明更精简
  - 图片占位区 `aspect-[4/3]`
  - tags + GitHub
- **留白**:两个区块之间 `gap-8 lg:gap-12`,每个区块内部 `space-y-6`
- **新增组件 `ProjectFeature`**:替代当前 `ProjectCard`,支持大/小两种尺寸 variant + 图片占位区
