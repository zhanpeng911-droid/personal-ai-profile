# 前端全面重写计划：Tech Innovation 深色科技 + shadcn/ui

## 设计方向
基于 frontend-design skill 方法论 + theme-factory Tech Innovation 主题，打造有辨识度的深色科技美学，告别 AI slop。

### 配色
- 主背景 `#0d0d0f`（近黑微暖，非纯黑）
- 表面层 `#1a1a1e` / `#16161a`（两级卡片层次）
- 主强调 `#0066ff`（电蓝，用于 CTA/链接/重点）
- 高亮 `#00e5ff`（霓虹青，用于数据/状态/光效）
- 文字 `#f5f5f7`（主）/ `#a3a3a8`（次）/ `#52525a`（弱）
- 点缀 `#fbbf24`（暖琥珀，仅用于配额低/警示，克制使用）

### 字体（告别 Inter）
- **标题**: Bricolage Grotesque（有性格的展示字体，Google Fonts 可用）
- **正文**: Outfit（几何无衬线，与标题对仗）
- **等宽**: JetBrains Mono（代码/数据/来源 id）
- 加载方式: next/font/google（解决当前 `<link>` 阻塞问题）

### 视觉氛围（去 slop）
- **背景**: 噪点纹理（grain overlay）+ 几何线条装饰 + 深度渐变网格，替代当前通用渐变光球
- **破格元素**: 首屏不对称布局、对角线视觉流、grid-breaking 装饰线
- **动效**: 一次编排良好的首屏载入（staggered reveals 有节奏，非机械递增）；scroll-trigger 差异化（非全站统一 Reveal）；hover 令人惊喜的微交互
- **删除**: 通用 blob-drift 光球、渐变文字数字、统一 Reveal 错峰

## 实施步骤

### 第 1 步：基础设施
1. 安装依赖：`lucide-react`（图标库，替换内联 SVG）
2. 初始化 shadcn/ui（`npx shadcn@latest init`），添加组件：Button、Card、Input、Accordion、Badge、Separator、Tooltip
3. 用 next/font/google 加载 Bricolage Grotesque + Outfit + JetBrains Mono
4. 重写 `tailwind.config.ts`：Tech Innovation 配色 + 新字体 + 清理死代码动画
5. 重写 `globals.css`：噪点纹理背景、新组件原语、去 slop

### 第 2 步：ChatPanel 滚动修复 + 重设计（最优先）
**核心修复**：
- ChatPanel 改为固定视口高度 `h-[calc(100dvh-8rem)]`（而非 `min-h-[72vh]`）
- 顶栏 `shrink-0`（剩余次数永远可见，不随消息滚动消失）
- 消息区 `flex-1 overflow-y-auto`（唯一滚动区）
- 输入区 `shrink-0` 固定底部

**视觉升级**：
- 用 shadcn Card 重构容器
- 顶栏改为更紧凑的设计，配额用 Badge 组件
- 消息气泡差异化（用户/助手不同形态，非仅颜色不同）
- AI 思考动效用更精致的骨架/脉冲
- 来源引用用 Badge + Tooltip
- lucide 图标替换内联 SVG

### 第 3 步：首页重设计（HR 第一印象）
- **首屏**: 不对称布局，左侧大字标题（Bricolage Grotesque）+ 右侧装饰性数据面板。破格几何线条装饰。一次性编排载入动画（标题逐行、数据面板滑入、装饰线绘制）
- **数据亮点**: 重新设计为有冲击力的数字展示（2 独立项目 / 286+ 测试 / 114+ 测试），非渐变文字
- **项目预览**: 与项目列表页去重，首页改为横向特色展示（非重复的卡片网格）
- 移除 blob-drift 光球，改用几何线条 + 噪点纹理营造氛围

### 第 4 步：其他页面重设计
- **About**: 从三卡片堆叠改为时间线/信息流布局，差异化视觉节奏
- **项目列表**: 卡片重设计（lucide 图标 + 角色/时长徽章 + 技术栈可视化），去 "i*80" 机械延迟
- **项目详情**: 五个 section 差异化呈现（非同构卡片），架构示意区域
- **FAQ**: shadcn Accordion 替换原生 details，展开动画
- **Access**: 邀请码页视觉优化
- **Contact**: 招聘平台 + 联系方式重排

### 第 5 步：导航 + 全局
- **SiteHeader**: 保留移动端汉堡菜单（已实现），视觉用新配色/字体
- **SiteFooter**: 精简
- **Reveal 组件**: 保留但减少滥用，差异化延迟（非全站 `i*80`）

### 第 6 步：验证
- `npx tsc --noEmit` 类型检查
- `npm run lint`
- `npm run build`
- 手动验证 ChatPanel 滚动修复

- shadcn/ui 初始化可能与 Next.js 15 + React 19 有兼容问题 -> 若失败则回退到手写组件 + lucide 图标
- next/font 在受限网络下构建可能卡 -> 保留系统字体回退
- 全面重写改动大 -> 分步骤，每步可验证
