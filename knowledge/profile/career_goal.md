# 求职目标

正在寻找 **实习机会**，目标岗位类型：

1. AI Agent 工程师 / LLM 应用工程师
2. RAG / 知识库系统工程师
3. 后端工程师（偏 AI 应用）
4. 智能系统工程方向

## 关注点

- 可信检索与引用溯源（Evidence Grader、Citation Manager）
- 上下文工程（Context Pack、回合级裁剪、分层记忆）
- 可观测性与成本治理（JSONL 审计、Token 追踪、降级策略）
- 低成本可上线方案（文件型知识库、关键词检索、模型可降级）
- 安全边界（沙箱化工具执行、策略层权限控制、Prompt Injection 防护）
